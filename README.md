# stock-research

股票研究分析框架 Claude Code skill。自动识别美股/日股，逐条运行 **13 项标准化分析**，输出完整研究报告。

## 安装

```bash
# 克隆到 Claude Code skills 目录
git clone https://github.com/Ref96/stock-research.git ~/.claude/skills/stock-research
```

## 触发

| 输入示例 | 说明 |
|---------|------|
| `研究一下苹果` | 美股，按代码/公司名自动识别 |
| `分析 NVDA` | 直接代码触发 |
| `分析 7550` | 4位数字 = 日股 |
| `研究一下丰田` | 日本企业名自动识别为日股 |

## 13 项分析

| # | 分析项 | 美/日股差异 |
|---|--------|-----------|
| 1 | 商业理解 | 通用 |
| 2 | 收入分解 | 日股额外含汇率敏感度、国内/海外占比 |
| 3 | 行业背景 | 通用 |
| 4 | 竞争格局 | 日股额外含系列关系（Keiretsu）、外资压力 |
| 5 | 财务质量 | 日股额外含 ROE 改善轨迹、现金囤积判断 |
| 6 | 风险与下行 | 日股额外含日元升值冲击、治理风险 |
| 7 | 管理团队 | 日股聚焦 TSE 治理改革回应情况 |
| 8 | 牛熊情景 | 通用，含触发条件与验证指标 |
| 9 | 估值思考 | 日股额外含 PBR 修复路径分析 |
| 10 | 全球同类比价 | 通用，覆盖美/港/A/日/欧股 |
| **11** | **巴菲特市赚率** | **通用，PE÷ROE%，含 ROE 来源诊断** |
| **12** | **自由现金流质量** | **通用，FCF Margin / FCF/NI 质量比 / FCF Yield** |
| 13 | 长期论点 | 通用，核心理由 + 前提条件 + 出错信号 |

### #11 巴菲特市赚率

> 市赚率 = PE ÷ ROE%

| 区间 | 信号 |
|------|------|
| < 0.5 | ✓ 捡钱区间 |
| 0.5–0.8 | ✓ 便宜 |
| 0.8–1.2 | 合理 |
| 1.2–1.5 | 偏贵 |
| > 1.5 | ✗ 明显高估 |

参照锚点：巴菲特 1988 年买可口可乐 → PE 13.5 / ROE 33% → 市赚率 **0.41**

内置三种 ROE 失效诊断：回购虚高 / 杠杆虚高 / 跨行业失真，触发时强制标注不给出无效判断。

### #12 自由现金流质量

> FCF = 经营现金流 − 资本支出

三个核心指标 + FCF Yield 五档区间 + Capex 性质判断 + 五条警示信号（任一触发强制标注）。
